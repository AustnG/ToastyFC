# Toasty FC — Matchday Workflow Cheat Sheet (Phase 1)

This 60-second desktop workflow keeps `ToastyFC.com` current right after every game (filmed or unfilmed) and gives the Phase 2 AI video pipeline everything it needs for high accuracy.

---

## 1. Before the Game (When Weekly Schedule Drops)
Add 1 row in `Matches`:
- `id` (next sequential ID, e.g., `m95`)
- `seasonId` (e.g., `s12`) — `seasonName` auto-fills via formula
- `date` (`YYYY-MM-DD`), `time` (`HH:MM`), `opponent`, `type`, `location`
- `statsStatus` → **`Scheduled`** (`status` auto-shows `Upcoming`)

---

## 2. Right After the Game (60 Seconds in Google Sheets)
On that `Matches` row:
1. Enter **`toastyScore`** and **`opponentScore`** (`status` auto-flips to `Completed`).
2. Enter **`opponentColor`** (hex like `#1E40AF` or color name like `Blue`) — used by Phase 2 AI to separate teams from Toasty's `#cabba2` tan kit and color the highlight scoreboard bug.
3. Set **`statsStatus`** → **`Result Only`** (or **`Forfeit`**).
4. Optional: add **`ownGoalsFor`** (if opponent scored an own goal) or **`notes`** (e.g., `No film`, `Late Start Goal`, `Zac played GK`).
5. Click **Toasty FC → Log Match Attendance…** in the top menu, check off the players who showed up, and click **Add Attendance Rows**. *(Appends `matchId` + `playerId` rows to `MatchStats` with stat cells blank until Phase 2 populates them.)*
6. Click **Toasty FC → Publish to Website (ToastyFC.com)** → live in ~45–60 seconds!

---

## 3. Dropping Raw Footage on Synology NAS (`V:\`)
Select the match row in `Matches` and click **Toasty FC → Get NAS Folder Name (Selected Match)** to get the standard folder name:

```text
V:\ToastyFC\<Season>\<YYYY-MM-DD>_<matchId>_<Opponent>\
├── raw\                 # Untouched 4K Veo Gen 3 .mp4 or 1080p Mevo Start clips
├── match_config.json    # Optional override (auto-generated by Phase 2 if absent)
└── output\              # Generated by Phase 2: 1080p highlight .mp4, DaVinci .fcpxml, YouTube chapters
```

Putting `<matchId>` in the folder name lets the overnight Phase 2 script automatically pull that match's final score, attendance roster & jersey numbers, and opponent color straight from `Toasty FC Database`.
